INKY ZOMBIES 1.37 — PLAYER FIELD GUIDE

Open index.html in a browser. Keep the HTML, CSS and JavaScript files together.
JavaScript must be enabled; no server, account or internet connection is needed.
This guide does not install or modify the mod.

NEW IN 1.37

The Giant supports Boss Rush and ordinary added Panzer encounters. Added
Panzers can recover when stuck while pursuing a distant player, keeping their
remaining health and armor. Co-op admin pause holds the next wave after the
current round finishes and leaves everyone free to move and interact.
Verruckt remains unsupported for Boss Rush and ordinary added Panzers.

The 1.36 Panzer Overcharge damage correction remains: Insta-Kill does not
boost the intended elemental damage fractions against Panzers.

FROM 1.35: LARGER OVERCHARGE LIMITS

Elemental Overcharge has larger fixed limits: Lightning gets 96 total zaps,
Wind hits up to 64 targets, Ice hits up to 64 per pulse and Fire hits up to 24
per blast. These limits are the same in every match, regardless of Zombie Cap.
Damage, ranges and Lightning's once-per-boss rule are unchanged.
Selectable zombie caps and Reincarnation carry forward from version 1.34.

LOAD YOUR RUN

Select Inky Zombies from BO3's Mods menu before entering Zombies, and make sure
everyone in co-op uses the same mod version. The mod includes packages for all
supported BO3 game languages; Inky's custom text and settings are in English.

The host chooses match rules in INKY SETTINGS before launching. Defaults are
32 + Gradual zombie caps, Normal zombie difficulty, Medium Panzers and Scaling
Pack-a-Punch prices. Zombie Cap and Cap Progression are independent choices;
Reincarnation adds 8% compounding Panzer health with an 800,000 HP cap.
Classic disables the blessing only; movement, progression and perks remain.
Custom Map Panzers and Boss Rush on Custom Maps are separate settings, both
off by default. To use Boss Rush on a compatible custom map, enable its custom
map setting and select Boss Rush under Spiritual Blessing.

This reference describes the default rules. Host settings and map-specific
quests, weapons and enemy behavior can affect a run. Each topic explains the
exceptions that matter when making gameplay decisions.
