INKY ZOMBIES 1.2 — BOSS RUSH UPDATE — PLAYER FIELD GUIDE

Extract this entire folder and open index.html in a browser.
Keep the HTML, CSS and JavaScript files together. No server, account, internet
connection or installation is needed to read it. JavaScript must be enabled.

Use the left-hand topics, search box or Ctrl/Cmd+K to find a mechanic.
The Boss Rush page includes both full encounter schedules, spawn limits,
cumulative blessing unlocks, clear rewards and controlled support drops.
The perk reference has filters and expandable entries. The Panzer page includes
an encounter-health calculator and custom-map setup and compatibility guidance.
This guide does not install or modify the mod.
Load Inky Zombies 1.2 — Boss Rush Update from BO3’s Mods menu before entering
Zombies. Everyone in a co-op lobby should use the same mod version.

Select Boss Rush under Spiritual Blessing. On a custom map, also enable Boss
Rush on Custom Maps before launch. This is separate from Custom Map Panzers.
Boss encounters occur every third round, beginning on round 3. Each clear gives
Max Ammo and 1,000 / 2,000 / 5,000 points per eligible participant for the first,
second and every later clear. Shadows keeps native meatballs; other supported
maps use ordinary sprinters. See the guide for cumulative rewards, encounter
rosters and map compatibility details.

The guide describes the IZ 1.2 default rules, reviewed on 18 October 2026.
Defaults are Normal zombie difficulty, Medium Panzers and Scaling PaP prices.
PaP prices stop rising at round 21: 50,000 for an upgrade and 25,000 for a
repack. Heroic, Nightmare and Fixed PaP prices are optional host settings.
Host settings and map-specific mechanics can change gameplay. Exact tuning may
change in later mod updates.
